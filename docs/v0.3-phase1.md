# Gogogo v0.3 Phase 1 — fixed landmarks and collision foundation

Baseline: `d586c7943dacf726d6d4cddda4bd732b5442c231` (working v0.2).

## Implemented Phase 1 foundation
- `WorldManifest.js`: frozen identity, position, footprint and collision profiles for Clock Square, Metro Terminal, Welcome Gate, Sunrise Plaza and Skyport airport. Current positions are unchanged.
- `LandmarkColliders.js`: compound Rapier colliders for the four landmarks previously represented mainly as artwork. Airport terminal retains its existing collision owner.
- Protected plots prevent overlapping generic buildings. `stableParcelSeed(i,j)` is available for future individual plot generation. Existing global random sequence is intentionally not replaced during Phase 1, so the surrounding city is not needlessly regenerated.
- `SurfaceSystem.js`: authoritative terrain height, city/airport road footprints, material classification and ground mesh creation. The visual ground vertices use the exact sample grid supplied to Rapier.
- `World.js`: road/shoulder layers use small deliberate rendering offsets from physical terrain; this is *visual dressing only*, not a replacement for physical wheel/curb geometry. Future detailed roads need authored local collision patches with independently validated continuity.
- `Vehicle.js`: road vs off-road traction uses the shared surface definition rather than its own divergent grid logic.
- Preserved `voxel-city-driver:v1`, save schema version 1 and the existing player garage, progress and settings.
- Added unit tests for terrain sample agreement, protected plots, stable landmark coordinates, surface types and old save migration; added real-browser assertions for installed landmark colliders.

## Explicit Phase 1 limits
- This does not build mountain roads, beaches, wind, rain, potholes or per-wheel suspension. Those belong after the foundation is verified.
- A common sample grid guarantees identical vertex samples, but Rapier and Three.js may use different diagonal choices within an individual heightfield cell. Continuous contact tests and detailed road-collider integration remain required.
- Legacy apron and runway slabs are not yet replaced by a unified road tessellator. Terrain beneath them is grounded; the new road-system reconstruction is a later step.
- Current four public landmark assets still use the existing voxel style; their shapes and locations are intentionally preserved.
- The large airport area uses the preexisting terminal collider rather than duplicate colliders.
- Parcel placement can still be upgraded to fully per-parcel deterministic seeds after the fixed-map regression passes.

## Next gate
Run `npm run check`, `npm run build`, browser smoke against deployed assets, and inspect real-browser screenshots. Independently test vehicle impacts with clock tower, metro, arch pillars and airport terminal. Do not begin mountain height/road work until this foundation passes.
